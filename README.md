# localized-rnb-dex

A Pokédex for the **Pokémon Run & Bun** ROM hack. It is a near copy of
[RBDex](https://may8th1995.github.io/RBDex/), which is a fork of the Pokémon Showdown Dex. This copy has two changes:

1. **Ability descriptions are back.** Pokémon Showdown stopped adding `desc` and `shortDesc` to its `data/abilities.js`
   on 2026-09-13 (client commit `fccc266fe`). The text is now in `data/text/en.js`. The build merges that text
   into `public/data/abilities.js`.
2. **Nothing comes from another site.** Sprites, cries, icons, fonts, stylesheets, and data files are in this repo.
   Changes at Showdown cannot break the site.

The site is fully static. Every page is `public/index.html`. The router (`public/js/router.js`) uses `pushState`,
so the host must serve `index.html` for paths without a file, such as `/abilities/intimidate`.

## Run locally

```sh
npm install
npm run dev
```

`npm run dev` builds the site. Then it serves the site at http://localhost:8787 with the `index.html` fallback.

## Build

`npm run build` writes two generated outputs. Git ignores both.

| Output | Contents |
| --- | --- |
| `public/data/abilities.js` | Ability data with descriptions. |
| `public/articles-cached/` | The articles, made from `content/articles/*.md`. |

## Deploy to Cloudflare Workers

```sh
npx wrangler login
npm run deploy
```

`wrangler.jsonc` sets `build.command` to `npm run build`, so `wrangler deploy` builds first. The file also serves
`public/` as static assets with `not_found_handling: "single-page-application"`.

If you deploy another way, such as Workers Builds or `wrangler versions upload`, run `npm run build` before the deploy.
Git does not store the generated files. A deploy without a build has no ability data and no articles. Leave the
dashboard build command empty, or set it to `npm run build`.

The deploy uploads about 18,100 files. The Workers Free limit is 20,000 files per version.
`public/_headers` adds a one-week cache to sprites, cries, and fonts.

## Layout

| Path | Contents |
| --- | --- |
| `public/` | The whole site. This is the deploy root. |
| `public/data/abilities.js` | Generated by `npm run build`. Not committed. |
| `public/articles-cached/` | Generated by `npm run build`. Not committed. |
| `public/sprites`, `public/audio`, `public/style` | Downloaded from play.pokemonshowdown.com by `npm run fetch:assets`. Committed. The path layout is the same as at Showdown. |
| `public/*.js` data files | Run & Bun data from RBDex: `pokedex.js`, `moves.js`, `items.js`, `learnsets.js`, `locations.js`, `teambuilder-tables.js`. |
| `upstream/` | Showdown snapshots that the scripts read: `abilities.js`, `text/en.js`, `typechart.js`, `aliases.js`, `config.js`, and CSS. It also has `species-sprites.json`, the sprite id of each species. |
| `upstream/missing-assets.txt` | Files that Showdown does not have, such as forme sprites and cries. They also return 404 on RBDex. |
| `upstream/extra-assets.txt` | Paths that the crawl found missing locally. |
| `upstream/rbdex/` | The origin of this copy: the RBDex `README.md`, its `cms/build` article script, and the `COMMIT` file. |

## Changes from RBDex

- `index.html`: Every remote `<script>` and `<link>` points to a local file. The page title is "Run & Bun Pokédex".
- `battledata.js`: `Dex.resourcePrefix` returns `/` and `Dex.fxPrefix` returns `/fx/`. The Pokémon icon sheet URL is local.
- `js/pokedex-moves.js`: The TM and tutor icons use `Dex.resourcePrefix`.
- `js/pokedex.js`: Articles load from `/articles-cached/`. RBDex loaded them from `/.articles-cached/`, which it never
  committed, so article pages did not load on GitHub Pages.
- The PHP files (`.htaccess`, `index.template.php`, `build`) are removed.

## Update the data

Nothing updates by itself. To use newer Showdown ability text:

1. Download `https://play.pokemonshowdown.com/data/abilities.js` to `upstream/data_abilities.js`.
2. Download `https://play.pokemonshowdown.com/data/text/en.js` to `upstream/data_text_en.js`.
3. Run `npm run build`.

To change Run & Bun data (Pokémon, moves, locations), edit the matching file in `public/`.

## Find missing assets

`npm run fetch:assets` uses rules about which files each page requests. `npm run find:missing` checks those rules
against the real pages.

1. Run `npm run dev`.
2. Start Chrome or Brave with `--remote-debugging-port=9222`.
3. Run `npm run find:missing`. The script opens every species page and type page. It writes each local 404 to `upstream/extra-assets.txt`.
4. Run `npm run fetch:assets` to download those files.

A path that still returns 404 after step 4 is a file that Showdown does not have.

## Checks

`npm test` builds the site. Then it tests the ability text and the `index.html` fallback.

`npm run check:offline` makes sure that `index.html` and the CSS use only local files that exist. Run `npm run build` first.
